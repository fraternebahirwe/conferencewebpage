## ✨ Features & Sections

- **Hero Banner:** Event title, topic badge highlights, and dual call-to-action buttons.
- **Event Info Bar:** Key conference overview details (Date, Kigali location, Sessions, Community).
- **About Section:** Mission statement, event goals, and highlights on why to attend.
- **Program Schedule:** Structured schedule listing keynotes, talks, and breaks with timestamps using HTML `<time>` tags.
- **Featured Speakers Grid:** Interactive speaker cards with links to developer social profiles (GitHub, Facebook).
- **Call-To-Action & Contact:** Direct interaction links via WhatsApp chat and email (`mailto:`).
- **Comprehensive SEO & Meta Tags:** Open Graph protocol, canonical URL, and search engine optimization configuration.

---

## 🛠️ Built With

- **HTML5:** Semantic landmark structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), Open Graph metadata, and full screen-reader accessibility.
- **CSS3:** Custom styles, dark theme, and responsive grid/flexbox layouts (`conference.css`).
- **JavaScript (ES6+):** Client-side navigation logic and interaction handling (`conference.js`).
